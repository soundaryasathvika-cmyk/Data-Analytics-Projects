# AdventureWorks Sales  – SQL

## Project Overview

This project analyzes AdventureWorks sales data using SQL to identify sales performance, customer behavior, product trends, regional performance, and other key business insights.

The project demonstrates the use of SQL for data extraction, transformation, analysis, and business reporting.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Database Tables

The analysis uses AdventureWorks sales-related tables, including:

- FactInternetSales
- DimProduct
- DimCustomer
- DimDate
- DimSalesTerritory

## Key Analysis

- Overall sales performance
- Product-wise sales analysis
- Customer-wise sales analysis
- Region and territory performance
- Year-wise and month-wise sales trends
- Order quantity analysis
- Top-performing products
- Top customers
- Sales by territory
- Year-over-year sales comparison

## Advanced SQL Analysis

### Customer Analysis

Analyzed customer purchasing behavior and ranked customers based on sales and order activity.

### Product Analysis

Identified top-performing products based on sales and order quantities.

### Regional Analysis

Analyzed sales performance across different sales territories and regions.

### Time-Based Analysis

Analyzed sales trends by year, month, and other time periods to understand business performance over time.

### Year-over-Year Analysis

Used SQL date functions and window functions to compare sales performance across different years.

## Key Insights

The analysis helps identify:

- Best-performing products
- High-value customers
- Strong-performing regions and territories
- Sales trends over time
- Changes in sales performance
- Customer purchasing patterns
- Product demand based on order quantities
