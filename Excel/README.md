# AdventureWorks sales – Excel

## Project Overview

This project analyzes AdventureWorks sales data using Microsoft Excel to identify sales performance, product trends, customer insights, and other key business metrics.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Analysis

- Sales performance analysis
- Product-wise sales analysis
- Customer analysis
- Regional sales analysis
- Time-based sales trends
- Key performance indicators (KPIs)

## Project File

The Excel workbook contains the complete analysis, calculations, and visualizations.

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Excel Functions
- Pivot Tables and Charts
- Data Visualization
