# Adventure Works Sales – Tableau

## Project Overview

This project analyzes AdventureWorks sales data using Tableau to identify sales performance, product trends, customer insights, regional performance, and business trends.

An interactive Tableau dashboard was created to transform sales data into meaningful visual insights and support data-driven decision-making.

## Tools Used

- Tableau
- Tableau Public
- Data Visualization

## Key Analysis

- Overall sales performance
- Profit and sales analysis
- Product-wise sales performance
- Customer analysis
- Regional sales analysis
- Year-wise sales trends
- Monthly sales trends
- Top-performing products
- Top customers
- Profitability analysis

## Dashboard Features

The dashboard includes:

- KPI Cards

- Region-wise analysis
- Product analysis
