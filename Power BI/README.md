# AdventureWorks Sales Analysis – Power BI

## Project Overview

This project analyzes AdventureWorks sales data using Power BI to evaluate sales performance, product trends, customer insights, regional performance, and key business metrics through an interactive dashboard.

## Tools & Techniques Used

- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Modeling
- Data Visualization
- Interactive Dashboard

## Key Analysis

- Sales performance analysis
- Product-wise sales analysis
- Customer analysis
- Regional sales analysis
- Monthly and quarterly sales trends
- Key Performance Indicators (KPIs)
- Year-over-Year sales analysis

## Dashboard

The Power BI dashboard provides interactive visualizations and KPI cards to help analyze overall sales performance and identify important business insights.

## Project File

The Power BI `.pbix` file contains the complete data model, transformations, DAX calculations, and interactive dashboard.

## Skills Demonstrated

- Data Cleaning & Transformation
- Power Query
- Data Modeling
- DAX Calculations
- Data Visualization
